# Python Projects

A collection of my Python programs built while learning core programming concepts

## Battleship_revisited.py
Console-based Battleship game. Ships are placed randomly on a 5x5 grid and tracked using a dictionary keyed by coordinate. Validates guesses, tracks hits/misses, and reveals remaining ships if the player loses.

## fake_wordsearch.py
Word search generator and solver. Reads a word list from a file, places the words into a grid while avoiding overlaps, fills empty spaces with random letters, and validates player guesses by coordinate range. Writes a results summary to an output file.

## Project.py
Final project for ITSS 3311 (Object-Oriented Programming). A branching choose-your-own-adventure text game built as a state machine — the current "path" drives which story text and choices are shown next, with all content stored in dictionaries rather than hardcoded.

## Calculator.py
Basic command-line calculator supporting add, subtract, multiply, and divide, with input validation.

## guess_number.py
Number-guessing game with a limited number of attempts and a scoring system based on how many guesses it took.
